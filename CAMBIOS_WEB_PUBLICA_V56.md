# Metamorfosis Web v5.6

## Base utilizada
Esta versión fue trabajada sobre `Metamorfosis-main (12).zip`.

## Objetivo del ajuste
Reducir saturación visual y mejorar conversión hacia el formulario **Conversemos**, manteniendo el tono profesional del laboratorio.

## Cambios principales
- Reducción del tamaño y longitud de varios títulos para evitar que compitan con el contenido.
- Mayor jerarquía de lectura en las secciones principales.
- Íconos más grandes y legibles en mapa, tarjetas, método, principios y equipo.
- Tarjetas de investigación aplicada simplificadas y más compactas.
- Tarjetas de situaciones con títulos y textos más breves.
- Nuevo llamado intermedio a la conversación antes del formulario final.
- Nueva capa CSS comentada: `WEB PÚBLICA V5.6 · AJUSTE DE ATENCIÓN, JERARQUÍA Y CONVERSIÓN`.
- Se agregó la clase raíz `public-site--v56` para encapsular los ajustes sin romper la base previa.
