# Metamorfosis Web v5.16

## Criterio general
La versión 5.16 recupera la composición visual del esquema que mejor funcionó: una lectura central, elementos subordinados y profundidad solo cuando el usuario decide abrirla.

## Cambios
- Hero conserva la proporción visual aprobada y evita que el título invada el manifiesto.
- `Qué hacemos` cabe cerrado en una sola escena y sus dos motores son clickeables.
- `Qué cultivamos` y `Criterios de trabajo` pasan a ser dos columnas de botones dentro de `Jardín de innovación`.
- Se elimina la sección independiente de principios y la sección independiente de cultivo.
- `Qué observamos` recupera la composición 2 + Metamorfosis al centro + 2.
- `Cómo trabajamos` aparece como una escena propia debajo del mapa.
- Se elimina el número/círculo de sección “02”; se mantienen solo los números de las cinco etapas.
- Las cinco etapas ya no reservan espacio vacío. Cerradas son compactas; al abrirlas crece solo la tarjeta elegida.
- Varias etapas pueden permanecer abiertas al mismo tiempo.
- Varias dimensiones, líneas cultivadas y criterios también pueden quedar abiertos simultáneamente.
- En móvil los bloques se transforman en una secuencia táctil vertical.
