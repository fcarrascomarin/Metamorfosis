# Migración del sistema operativo dual

El HTML anterior contiene información personal y financiera que no debe subirse directamente a un repositorio público.

Para trasladar su estado:

1. Abre `sistema_operativo_dual_final_julio_2026.html` localmente.
2. Presiona **Respaldar** para descargar el JSON.
3. Ingresa a `/admin` en Metamorfosis.
4. Presiona el icono **Importar respaldo JSON** del encabezado.
5. Selecciona el respaldo.
6. Revisa el contenido y presiona **Guardar cambios**.

Metamorfosis OS completa identificadores faltantes y admite la estructura de tareas, guías, frentes, decisiones y bandeja del sistema anterior. Los campos financieros antiguos se conservan en el respaldo, pero la nueva interfaz muestra únicamente finanzas del negocio para evitar mezclar información familiar en la plataforma empresarial.
