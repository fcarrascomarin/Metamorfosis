# Metamorfosis Web v5.12

## Objetivo
Ajuste de jerarquía y distribución para que cada escena se entienda de inmediato, con títulos principales de una sola línea en escritorio, textos completos y tarjetas compactas que crecen únicamente cuando se abren.

## Cambios principales
- El Jardín fue reorganizado para caber en una sola pantalla de escritorio en estado cerrado.
- El título del Jardín ocupa todo el ancho útil y ya no queda comprimido en una columna.
- El contenido introductorio se divide en dos ideas breves y paralelas.
- “¿Por qué jardín?” pasa a ser una franja compacta.
- “Cuándo vale la pena intervenir” permanece dentro del Jardín, pero usa menos altura.
- Las tarjetas de entrada muestran el título completo y solo crecen cuando el usuario abre una explicación.
- Los títulos principales de las escenas quedan en una sola línea en escritorio.
- Se acortaron títulos de Investigación, Equipo, Principios y Contacto para reforzar claridad y evitar saltos de línea.
- El hero separa “Crecer con claridad” de “Operar con precisión”, manteniendo ambas expresiones en una línea.
- Principios se reorganiza con encabezado horizontal y cuatro criterios compactos.
- Se aumentó la separación visual entre las columnas del equipo.

## Edición rápida
En `src/styles.css`, buscar:
`WEB PÚBLICA V5.12 · UNA IDEA POR PLANA · TÍTULOS EN UNA LÍNEA`

El bloque contiene 12 apartados comentados para ajustar cada zona sin recorrer el CSS completo.
