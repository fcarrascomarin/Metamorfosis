# ACTUALIZACIÓN 5.1.0 · narrativa visual pública

## Alcance
- Se rediseña la experiencia pública manteniendo el OS con doble espacio Empresa/Familiar.
- Se mejora específicamente la lectura de las secciones **Qué hacemos**, **Método** y **Equipo**.

## Cambios principales

### 1. Qué hacemos
- Se reemplaza la grilla simple por una vitrina visual de tres pilares.
- Cada pilar incorpora ilustración propia, titular breve y texto acotado.
- Los casos de entrada se muestran como tarjetas compactas, legibles y alineadas.

### 2. Método
- Se incorpora una secuencia de cuatro tarjetas visuales: Entender, Priorizar, Intervenir y Medir y transferir.
- Cada etapa incluye imagen, numeración visible y una explicación corta.
- Los principios del método quedan debajo como una segunda capa de lectura, sin saturar.

### 3. Equipo
- Se agrega una capa visual con profesión / área y casa de estudio o formación.
- Se usan chips de color diferenciados para no mezclar esa información con el rol principal.
- La estructura quedó preparada para editar fácilmente los datos desde `src/publicContent.js`.
